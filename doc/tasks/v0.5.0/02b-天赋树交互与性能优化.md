## 详细步骤

### 1. 鼠标滚轮缩放

```java
setOnScroll(event -> {
    double oldScale = scale;
    
    // 缩放范围 0.1x ~ 2.0x
    if (event.getDeltaY() > 0) scale = Math.min(2.0, scale * 1.1);
    else scale = Math.max(0.1, scale / 1.1);
    
    // 以鼠标位置为中心缩放
    double mx = event.getX(), my = event.getY();
    offsetX += (mx - getWidth() / 2) * (1 / oldScale - 1 / scale);
    offsetY += (my - getHeight() / 2) * (1 / oldScale - 1 / scale);
    
    render();
});
```

### 2. 鼠标拖拽平移

```java
// 中键或右键拖拽
setOnMousePressed(event -> {
    if (event.getButton() == MouseButton.MIDDLE || 
        event.getButton() == MouseButton.SECONDARY) {
        lastMouseX = event.getX();
        lastMouseY = event.getY();
        dragging = true;
    }
});

setOnMouseDragged(event -> {
    if (!dragging) return;
    double dx = event.getX() - lastMouseX;
    double dy = event.getY() - lastMouseY;
    offsetX -= dx / scale;
    offsetY -= dy / scale;
    lastMouseX = event.getX();
    lastMouseY = event.getY();
    render();
});
```

### 3. 节点悬停检测

```java
setOnMouseMoved(event -> {
    double wx = screenToWorldX(event.getX());
    double wy = screenToWorldY(event.getY());
    
    double hitRadius = 12 / scale;
    int found = tree.findNearestNode(wx, wy, hitRadius);
    
    if (found != hoveredNodeId) {
        hoveredNodeId = found;
        if (found != -1) showNodeTooltip(found, event.getScreenX(), event.getScreenY());
        else hideTooltip();
        render();
    }
});
```

### 4. 节点点击

```java
setOnMouseClicked(event -> {
    if (event.getButton() != MouseButton.PRIMARY) return;
    if (hoveredNodeId == -1) return;
    
    selectedNodeId = hoveredNodeId;
    AppEventBus.postSync(new NodeSelectedEvent(selectedNodeId));
    render();
});
```

### 5. 搜索定位 + 平滑动画

```java
public void navigateToNode(int nodeId) {
    PassiveSkill node = tree.getNode(nodeId);
    double targetX = node.getX(), targetY = node.getY();
    
    AnimationTimer timer = new AnimationTimer() {
        long start = System.nanoTime();
        double startX = offsetX, startY = offsetY;
        
        @Override
        public void handle(long now) {
            double t = Math.min(1, (now - start) / 200_000_000.0);
            double eased = 1 - Math.pow(1 - t, 3);  // easeOutCubic
            offsetX = startX + (targetX - startX) * eased;
            offsetY = startY + (targetY - startY) * eased;
            if (t >= 1) stop();
            render();
        }
    };
    timer.start();
}
```
