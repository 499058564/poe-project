## 任务描述

实现装备制作模拟的核心逻辑：词缀池、工艺步骤、成本计算、概率估算。

## 详细步骤

### 1. CraftingSimulator

```java
public class CraftingSimulator {
    
    /** 获取物品可用的工艺选项 */
    public List<CraftingOption> getAvailableOptions(Item base) { ... }
    
    /** 模拟单个工艺步骤 */
    public CraftingResult applyCraft(Item item, CraftingOption option) { ... }
    
    /** 模拟完整制作流程 */
    public SimulationResult simulateCrafting(
            Item base, List<CraftingStep> steps, int iterations) { ... }
    
    /** 计算期望成本 */
    public CostEstimate estimateCost(List<CraftingStep> steps) { ... }
}
```

### 2. CraftingOption（工艺选项）

```java
public class CraftingOption {
    String name;            // "蜕变石" / "改造石" / "富豪石" / ...
    String currency;        // 使用的通货
    CraftingType type;      // CURRENCY / BENCH / FOSSIL / ESSENCE / HARVEST
    Map<String, Double> modWeights;  // 影响词缀权重的修改
    int requiredItemLevel;
}
```

### 3. CraftingStep（制作步骤）

```java
public class CraftingStep {
    CraftingOption option;
    int repeatCount;        // 重复次数（如改造石洗 500 次）
    String targetMod;       // 目标词缀（用于判断是否成功）
    StopCondition stopCondition;  // 停止条件
}

enum StopCondition {
    ANY_TARGET_MOD,      // 出现任意目标词缀
    ALL_TARGET_MODS,     // 出现所有目标词缀
    MIN_TIER,            // 达到最低阶级
    SPECIFIC_TIERS       // 特定词缀组合
}
```

### 4. 概率计算

```java
// 基于词缀权重和标签限制计算概率
// 1. 筛选可用词缀池（根据物品基底、物等）
// 2. 计算各词缀出现概率 = 权重 / 总权重
// 3. 结合工艺步骤计算累积概率
// 4. 蒙特卡洛模拟（大量迭代取平均值）
```

### 5. CostEstimate（成本估算）

```java
public class CostEstimate {
    int expectedAttempts;         // 期望尝试次数
    Map<String, Integer> currencyCost;  // 通货消耗
    double totalValue;            // 总价值（混沌石计价）
    double confidenceInterval;    // 置信区间
    int iterations;               // 模拟次数
}
```
