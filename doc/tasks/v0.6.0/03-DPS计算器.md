### 3. Build 对比

```java
// 两个 Build 对比
// 差异用绿色（提升）/红色（降低）标注
class BuildComparison {
    Build buildA, buildB;
    Map<String, DiffLine> statDiffs;  // 逐项对比
}

class DiffLine {
    double valueA, valueB;
    double diffPercent;
    boolean isImprovement;
}
```
