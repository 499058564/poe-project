## 任务描述

实现装备制作模拟的 UI 页面，提供可视化的制作流程配置和结果展示。

### 2. 基底选择

- [ ] 搜索框：搜索装备基底
- [ ] 按类别过滤：戒指、项链、武器、护甲...
- [ ] 显示物等、基底属性
- [ ] 选中后显示可选词缀列表

### 3. 制作步骤编辑

- [ ] 步骤列表（可拖拽排序、添加/删除）
- [ ] 每个步骤选择工艺类型和参数
- [ ] 步骤模板（常用制作套路一键加载）
- [ ] 步骤预览：显示每步可能结果

### 4. 结果展示

- [ ] 期望尝试次数 + 分布图
- [ ] 通货消耗明细
- [ ] 最终物品模拟预览
- [ ] 导出制作流程为文本

### 5. 预设模板

- [ ] 高血量戒指
- [ ] 召唤法杖
- [ ] 元素弓
- [ ] ES 胸甲
- [ ] 用户自定义模板保存

## 验收标准

- [ ] 完整制作流程可配置
