### 2. FTS 搜索 SQL

```sql
-- 模糊匹配
SELECT b.*, fts.rank
FROM items_fts fts
JOIN base_items b ON fts.rowid = b.id
WHERE items_fts MATCH ?
  AND (? IS NULL OR b.class = ?)
ORDER BY fts.rank
LIMIT ? OFFSET ?
```

### 3. 搜索结果模型

```java
class ItemSummary {
    int id;
    String name;
    String nameZh;
    String itemClass;
    int dropLevel;
    String iconUrl;  // Wiki 图标 URL（如有）
}

class ItemDetail {
    ItemSummary summary;
    List<String> implicits;
    Map<String, Integer> requirements;  // {str: 100, dex: 50}
    List<ModLine> explicitMods;
    String flavourText;
    String wikiUrl;
}

class SearchResult<T> {
    List<T> items;
    int total;
    int page;
    int pageSize;
    boolean hasMore;
}
```

## 验收标准

- [ ] 搜索 "Mageblood" → 返回 "Mageblood" 物品
- [ ] 搜索 "法师之血" → 返回相同结果
- [ ] 按类别过滤 "武器" → 只返回武器类物品
- [ ] 分页：第 1 页 50 条，第 2 页不同数据
- [ ] 空搜索词 → 返回空结果或全部（根据设计决定）
