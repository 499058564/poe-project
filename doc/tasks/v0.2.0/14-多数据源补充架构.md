**前置**：T-013, T-016~T-021

## 任务描述

Wiki Cargo API 页面数据与当前游戏版本同步。所有核心表（items、skill_gems、passive_skills、mods 等）API 均可正常查询。引入 poe.ninja API、GGG 官方 API、POB 社区数据作为补充数据源，建立多源数据架构。

## 子任务

### 1. poe.ninja API 客户端（T-022a）

```java
public class PoeNinjaClient {
    // 公开 REST API，无需认证
    // rate limit: ~1 req/s（社区约定）
    
    /** 获取当前赛季物品价格 */
    public List<CurrencyPrice> getCurrencyOverview(String league) { ... }
    public List<ItemPrice> getItemOverview(String league, String type) { ... }
    
    // 支持的 item type: Currency, Fragment, Scarab, Fossil, Resonator,
    //   Essence, DivinationCard, SkillGem, BaseType, UniqueMap, etc.
}
```

**特点**：
- 无需认证，公开 REST API
- 覆盖范围：经济数据（价格/流行度）+ 赛季名
- 数据版本：按 league 名分（Settlers, Affliction 等）
- 价值：提供最新赛季经济数据，弥补 Wiki 过时问题

### 2. GGG 官方 API 客户端（T-022b）

```java
public class GggApiClient {
    // base URL: https://api.pathofexile.com
    // OAuth2 for account endpoints
    
    /** 获取赛季列表 */
    public List<League> getLeagues() { ... }
    
    /** 获取天梯数据 */
    public List<LadderEntry> getLadder(String league, int limit) { ... }
    
    /** 获取账号信息（需 OAuth） */
    public AccountProfile getProfile() { ... }
}
```

**特点**：
- 公开端点无需认证（league, ladder）
- OAuth2 端点需用户授权（profile, item-filter）
- ⚠️ 不暴露游戏数据（物品、技能、天赋等）
- 价值：权威赛季版本检测

### 3. POB 社区数据提取（T-022c）

```java
public class PobDataExtractor {
    // 从 pob-runtime/src/main/pob 提取数据文件
    // 解析 Lua/JSON 格式的游戏数据
    // ⚠️ 补充用途：POB 可验证/补充 Wiki 数据的完整性，但不作主数据源
    
    /** 从游戏数据文件提取技能宝石定义（验证用） */
    public List<SkillGem> extractSkillGems() { ... }
    
    /** 提取当前游戏版本号（备用） */
    public String extractGameVersion() { ... }
}
```

**特点**：
- 数据来自游戏客户端提取（最完整）
- 随 POB 更新保持当前版本
- 价值：验证 Wiki 数据完整性、获取精确版本号
- 已有 `pob-runtime` 子模块，直接复用
