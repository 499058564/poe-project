## 任务描述

从 Wiki Cargo API 同步装备物品子表数据。`items` 主表已同步（T-013），子表包含各类物品的特有字段。

## 涉及的 Wiki Cargo 表

| 表名 | 行数 | 字段 |
|------|------|------|
| `base_items` | ~1,200 | name, item_class, required_level, str/dex/int, drop_level, inventory_icon |
| `weapons` | 691 | physical_damage_min/max, critical_strike_chance, attack_speed, weapon_range |
| `armour` | ~300 | armour, evasion, energy_shield (per piece type) |
| `shields` | 179 | block_chance, armour/evasion/energy_shield |
| `amulets` | ~150 | talisman_type, implicit_stats |
| `flasks` | 91 | flask_type (life/mana/utility), duration, charges_max, charges_per_use |
| `jewels` | 165 | jewel_type (cobalt/crimson/viridian/abyss/cluster), jewel_radius, jewel_limit |
| `stackables` | 1,368 | stack_size, currency_tab_id, description |
| `maps` | 469 | map_tier, atlas_region, unique_boss, series |
| `map_fragments` | 173 | fragment_type (sacrifice/mortal/shaper/elder) |
| `map_series` | 27 | series_name, start_version, end_version |
| `divination_cards` | 468 | stack_size, reward_text, flavour_text, art_filename |

### ⚠️ 字段验证（实现前必须执行）

在编写 Converter 前，需逐表验证 Cargo 字段实际名称与任务文档是否一致：
1. 访问 `https://www.poewiki.net/wiki/Special:CargoTables/<table_name>` 查看完整字段列表
2. 或通过 API 测试：`cargoquery?tables=<table_name>&fields=_pageName&limit=1` 确认表可查询
3. 记录实际字段名，对比上表中列出的字段，修正不一致之处
4. 确认字段完全对齐后，再开始编写 Converter 和数据库迁移脚本

> 历史教训：`items` 表的 inventory_width/inventory_height 实际是 size_x/size_y；
> `passive_skills` 的 passive_class 实际不存在、stats 实际是 stat_text。
> Cargo 字段名 ≠ 猜测名，必须实测验证。

- `Armour.java` — 护甲特有属性
- `Shield.java` — 盾牌特有属性
- `Amulet.java` — 项链特有属性

- `Jewel.java` — 珠宝属性
- `Stackable.java` — 通货/可堆叠物品
- `Map.java` — 异界地图
- `MapFragment.java` — 地图碎片
- `MapSeries.java` — 地图系列
