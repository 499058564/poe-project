### ⚠️ 字段验证（实现前必须执行）

在编写 Converter 前，需逐表验证 Cargo 字段实际名称与任务文档是否一致：
1. 访问 `https://www.poewiki.net/wiki/Special:CargoTables/<table_name>` 查看完整字段列表
2. 或通过 API 测试：`cargoquery?tables=<table_name>&fields=_pageName&limit=1` 确认表可查询
3. 记录实际字段名，对比上表中列出的字段，修正不一致之处
4. 确认字段完全对齐后，再开始编写 Converter 和数据库迁移脚本

> 历史教训：Wiki Cargo 字段名可能与直觉不符（单数/复数、缩写、下划线格式差异）。
> 例如 `monsters` 表的 resistance 字段可能以 `resist_` 前缀命名，需实测确认。
