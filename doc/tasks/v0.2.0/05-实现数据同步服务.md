**模块**：`data-provider` + `data-cache`

## 任务描述

实现完整的数据同步流程：Wiki 拉取 → 数据转换 → SQLite 写入 → 索引更新。

## 详细步骤

### 1. DataSyncService

```java
public class DataSyncService {
    private final WikiApiClient wikiClient;
    private final DatabaseManager dbManager;
    
    /** 全量同步所有表 */
    public SyncResult syncAll() { ... }
    
    /** 同步指定表 */
    public SyncResult syncTable(String tableName) { ... }
    
    /** 检查远程是否有更新 */
    public boolean hasUpdates() { ... }
}
```

### 2. 同步流程

```
1. 获取远程记录总数
2. 对比本地 data_version 表
3. 如果一致 → 跳过
4. 如果不一致：
   a. 分批拉取（每批 500 条）
   b. 每批：转换数据 → 写入 SQLite → 更新进度事件
   c. 全部完成：更新 FTS 索引 → 更新 data_version
```

### 3. 数据转换器

```java
// 每个表一个转换器
public interface DataConverter<T> {
    T convert(JsonNode wikiRow);
}

ItemConverter implements DataConverter<Item>
SkillGemConverter implements DataConverter<SkillGem>
PassiveSkillConverter implements DataConverter<PassiveSkill>
ModConverter implements DataConverter<Mod>
```

### 4. 同步进度事件

```java
// 同步中实时发送进度
AppEventBus.postAsync(new DataSyncProgressEvent(
    "items", current, total
));

// 同步完成
AppEventBus.postAsync(new DataSyncCompleteEvent(
    "items", syncedCount, durationMs
));
```

### 5. 断点续传

```java
// 记录同步中断点
// 下次启动从中断位置继续
class SyncCheckpoint {
    String tableName;
    int lastOffset;
    Instant timestamp;
}
```

## 验收标准

- [ ] 首次运行完成全量同步（5 张核心表）
- [ ] 二次运行检测到无变化，跳过同步
- [ ] 同步进度事件正常发送
- [ ] 同步过程可中断和恢复
- [ ] 单表同步时间 < 30s（依赖网络）
