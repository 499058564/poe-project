### 2. 翻译数据来源

- [ ] 将 `https://github.com/Rayforward/PoeCharm2` 作为独立模块子模块引入 `poecharm2/`
- [ ] 优先复用 PoeCharm2 中已有的汉化词典/资源作为基础翻译数据
- [ ] 从 poedb.tw 爬取基础翻译数据
- [ ] 支持导入社区编年史翻译包（JSON 格式）
- [ ] 用户可在设置页面添加自定义翻译

### 3. 翻译数据格式

```json
// 社区翻译包格式
{
  "domain": "item",
  "version": "3.24",
  "entries": {
    "Mageblood": "法师之血",
    "Headhunter": "猎首",
    "Mirror of Kalandra": "卡兰德拉魔镜"
  }
}
```

### 4. 翻译缺失处理

- [ ] 翻译表中不存在时，显示英文原文并标记 `[待翻译]`
- [ ] 日志记录所有缺失翻译，便于后续补充
- [ ] 提供 "提交翻译" 功能（可选，v1.0+）

## 验收标准

- [ ] `translate("Mageblood", "item")` → `"法师之血"`
- [ ] `translate("UnknownItem", "item")` → `"UnknownItem"`
- [ ] 批量翻译 100 条 < 10ms
- [ ] 自定义翻译优先级高于内置翻译
- [ ] PoeCharm2 独立模块初始化后可导入并使用基础翻译数据
- [ ] 导入 JSON 翻译包后立即可用
