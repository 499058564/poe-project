# T-024 种子数据库与离线可用策略

**版本**：v0.2.0  
**模块**：`data-cache` + `app-core` + 根项目  
**预估**：1 天  
**前置**：T-013, T-015, T-007a  
**状态**：待开始

---

## 任务描述

构建应用内置种子数据库（`seed.db`），包含翻译数据和当前赛季 Wiki 数据，作为安装包的一部分分发。运行时实现「离线可用、在线增强」策略，确保用户在无网络或 Wiki 不可用时仍能正常使用。

## 背景

| 数据 | 变化频率 | 体积 | 打包策略 |
|---|---|---|---|
| PoeCharm2 翻译 | 极低（人工维护） | ~5 MB | ✅ 打包 |
| Wiki Cargo 数据 | 每赛季（3–4 月） | ~10 MB | ✅ 打包（当前赛季快照） |
| poe.ninja 价格 | 实时变动 | — | ❌ 不打包 |

**核心原则**：安装即可用，网络只是锦上添花。

## 详细步骤

### 1. 种子数据库构建任务

在根项目 `build.gradle.kts` 或独立脚本中注册 Gradle task：

```kotlin
tasks.register<JavaExec>("buildSeedDb") {
    group = "data"
    description = "构建内置种子数据库 seed.db"
    classpath = sourceSets["main"].runtimeClasspath
    mainClass.set("com.poe.cache.tool.SeedDbBuilder")
    args("--output", "${projectDir}/app-ui/src/main/resources/seed.db")
}
```

`SeedDbBuilder` 流程：
1. 创建临时 SQLite 数据库
2. 执行迁移脚本（建表）
3. 从 PoeCharm2 CSV 导入翻译数据（`importFromPoeCharm2`）
4. 从 Wiki Cargo API 拉取当前赛季快照（`syncAll`）
5. VACUUM 压缩数据库
6. 输出到 `app-ui/src/main/resources/seed.db`

> ⚠️ `buildSeedDb` 需要网络，仅在**发布构建时**执行，不在日常 `build` 中自动触发。

### 2. 运行时首次启动逻辑

`app-core` 新增 `DatabaseInitializer`：

```java
public class DatabaseInitializer {
    
    /**
     * 确保数据目录就绪。
     * 首次启动：复制 seed.db → ~/.poe-tool/data/poe.db
     * 非首次：直接返回已有数据库连接
     */
    public static Connection initialize() {
        Path dataDir = Path.of(System.getProperty("user.home"), ".poe-tool/data");
        Path dbPath = dataDir.resolve("poe.db");
        
        if (!Files.exists(dbPath)) {
            Files.createDirectories(dataDir);
            copySeedDb(dbPath);  // 从 classpath 复制 seed.db
        }
        
        return DriverManager.getConnection("jdbc:sqlite:" + dbPath);
    }
    
    private static void copySeedDb(Path target) throws IOException {
        try (InputStream in = DatabaseInitializer.class
                .getResourceAsStream("/seed.db")) {
            if (in == null) {
                throw new IOException("seed.db not found in classpath");
            }
            Files.copy(in, target);
        }
    }
}
```

### 3. 启动时后台自动同步

`app-core` 新增 `StartupSyncRunner`：

```java
public class StartupSyncRunner {
    
    /**
     * 异步执行，不阻塞 UI 启动。
     * 
     * 流程：
     * 1. 检查网络连通性（快速 ping）
     * 2. 有网络 → hasUpdates() → 有变化则 syncAll()
     * 3. 无网络 → 静默跳过，下次启动重试
     * 4. 同步失败 → 静默跳过，下次启动重试
     * 5. 通过 AppEventBus 发布结果（UI 可在状态栏显示）
     */
    public static void runAsync() {
        CompletableFuture.runAsync(() -> {
            try {
                if (!networkAvailable()) {
                    log.info("No network, skipping auto-sync");
                    return;
                }
                DataSyncService sync = createSyncService();
                if (sync.hasUpdates()) {
                    sync.syncAll();
                }
            } catch (Exception e) {
                log.warn("Auto-sync failed, will retry next launch", e);
            }
        });
    }
}
```

### 4. DatabaseManager 适配

修改 `DatabaseManager.getConnection()`：首次调用时委托给 `DatabaseInitializer.initialize()`。

```java
public Connection getConnection() throws SQLException {
    if (connection == null || connection.isClosed()) {
        if (testMode) {
            connection = DriverManager.getConnection("jdbc:sqlite:" + testDbPath);
        } else {
            connection = DatabaseInitializer.initialize();
        }
        init();
    }
    return connection;
}
```

### 5. 打包配置

`jpackage` 任务中确保 `seed.db` 包含在安装包中：

```kotlin
// app-ui/build.gradle.kts
tasks.processResources {
    from(rootProject.file("build/seed.db")) {
        into("")
    }
}
```

安装包体积估算：JRE (~40MB) + app jar (~5MB) + seed.db (~15MB) ≈ **60MB**。

## 验收标准

- [ ] `./gradlew buildSeedDb` 生成 `seed.db`，包含翻译数据和 Wiki 快照
- [ ] 首次启动自动复制 seed.db 到 `~/.poe-tool/data/poe.db`
- [ ] 断网环境下应用正常启动，搜索和翻译功能可用
- [ ] 有网时后台自动同步，不阻塞 UI 启动
- [ ] 同步失败不影响应用正常使用
- [ ] 非首次启动不再复制 seed.db（保留用户本地数据）
- [ ] `./gradlew jpackage` 生成的安装包含 seed.db
