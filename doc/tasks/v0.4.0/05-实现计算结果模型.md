## 任务描述

定义 POB 计算结果的结构化模型，覆盖攻击/防御/资源等所有计算维度。

## 详细步骤

### 1. CalculationResult

```java
public class CalculationResult {
    
    // === 攻击/法术 ===
    private StatLine totalDps;
    private StatLine averageHit;
    private StatLine attackSpeed;       // 或施法速度
    private double critChance;          // 暴击率
    private double critMultiplier;      // 暴击伤害
    private double hitChance;           // 命中率
    private double effectiveDps;        // 考虑命中的有效 DPS
    
    // === 防御 ===
    private StatLine life;
    private StatLine energyShield;
    private StatLine mana;
    private StatLine armour;
    private StatLine evasion;
    private Map<String, Double> resistances;  // fire/cold/lightning/chaos
    private double maxResistanceFire;
    private double maxResistanceCold;
    private double maxResistanceLightning;
    private double blockChance;
    private double spellBlockChance;
    private double spellSuppressionChance;
    private double armourReduction;      // 护甲减伤百分比
    
    // === 资源 ===
    private double manaRegen;
    private double lifeRegen;
    private double manaCostPerSecond;
    private int unreservedMana;
    private double unreservedManaPercent;
    
    // === 特殊机制 ===
    private double leechRate;
    private double lifeOnHit;
    private double manaOnHit;
    private Map<String, Double> ailments;   // shock/chill/freeze效果
    private Map<String, Double> charges;    // 球数量
    
    // === 原始数据 ===
    private Map<String, Double> allStats;   // POB 返回的所有原始统计项
}
```

### 2. StatLine

```java
public class StatLine {
    private double total;       // 最终值
    private double base;        // 基础值
    private double increased;   // inc% 总和
    private double more;        // more% 乘积
    private double added;       // 附加值
    private double effective;   // 有效值
}
```
