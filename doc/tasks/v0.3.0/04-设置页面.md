### 2. 功能实现

- [ ] 语言切换 → 实时更新 UI（发送 `ConfigChangedEvent`）
- [ ] 手动同步 → 触发 `DataSyncService.syncAll()`，显示进度条
- [ ] POB 路径选择 → 文件选择器（DirectoryChooser）
- [ ] POB 路径校验 → 检查目录是否包含 POB 关键文件
- [ ] 清除缓存 → 确认对话框 → 删除数据文件
- [ ] 显示缓存大小 → 计算 `~/.poe-tool/data/` 目录大小

### 3. 配置持久化

- [ ] 所有修改自动保存到 `config.json`
- [ ] 设置变更无需重启
