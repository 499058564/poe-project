## 任务描述

配置 jpackage 打包，生成 Windows 原生安装包。

## 详细步骤

### 1. 创建应用图标

- [ ] 设计/获取应用图标（256×256 PNG）
- [ ] 放置到 `app-ui/src/main/resources/icon.png`
- [ ] 在 `PoeApplication.start()` 中设置图标：
  ```java
  stage.getIcons().add(new Image("/icon.png"));
  ```

### 2. 配置 jpackage（`build.gradle.kts`）

```kotlin
// 在 app-ui/build.gradle.kts 中
tasks.register<Exec>("jpackage") {
    dependsOn("build")
    
    val installerType = "msi"  // 或 "exe"
    val appVersion = project.version
    
    commandLine(
        "jpackage",
        "--type", installerType,
        "--name", "POE-Tool",
        "--app-version", appVersion,
        "--vendor", "POE Community",
        "--icon", "src/main/resources/icon.ico",
        "--input", "build/libs",
        "--main-jar", "app-ui-$appVersion.jar",
        "--main-class", "com.poe.ui.PoeApplication",
        "--dest", "build/dist",
        "--win-menu",
        "--win-shortcut"
    )
}
```

### 3. 版本号注入

```kotlin
// 从 gradle.properties 读取版本号
// 在代码中通过 PoeApplication.VERSION 访问
tasks.processResources {
    filesMatching("**/version.properties") {
        expand("version" to project.version)
    }
}
```

## 验收标准

- [ ] `./gradlew jpackage` 生成 .msi 安装包
- [ ] 安装后可在开始菜单找到
- [ ] 应用图标正常显示
- [ ] 包含 JRE 运行时，无需用户安装 Java
- [ ] 安装包大小合理（< 100MB，不含数据）
