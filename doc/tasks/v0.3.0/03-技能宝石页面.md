## 任务描述

实现技能宝石搜索和详情页面，包括等级成长表格。

## 详细步骤

### 1. 页面布局

```
┌────────────────────────────────────────────────┐
│  [搜索技能...] [主动/辅助▼] [颜色▼] [标签▼]    │
├────────────┬───────────────────────────────────┤
│  宝石列表   │  宝石详情                         │
│            │                                   │
│ ⬤ 熔岩打击  │  ⬤ 熔岩打击                       │
│   主动,力量  │  主动技能宝石                       │
│            │  标签: 攻击, 近战, 火焰, 范围         │
│ ⬤ 多重打击  │  ─────────────────               │
│   辅助,力量  │  每 1% 品质:                       │
│            │  增加 1% 近战伤害                     │
│ ⬤ 冰霜射击  │                                   │
│   主动,敏捷  │  等级成长:                         │
│            │  ┌──────┬─────┬──────┐            │
│ ...        │  │ 等级  │ 需求 │ 伤害  │            │
│            │  │  1   │  1   │ 100% │            │
│            │  │  2   │  2   │ 102% │            │
│            │  │ ...  │ ...  │ ...  │            │
│            │  └──────┴─────┴──────┘            │
└────────────────────────────────────────────────┘
```

### 2. 过滤条件

- [ ] 宝石类型：全部 / 主动 / 辅助
- [ ] 属性颜色：全部 / 力量(红) / 敏捷(绿) / 智慧(蓝)
- [ ] 技能标签：攻击、法术、近战、范围、投射物等（多选）
- [ ] 搜索框：支持中英文

### 3. 宝石颜色标记

```
力量 (Str)   → 红色 #e05050
敏捷 (Dex)   → 绿色 #50e050  
智慧 (Int)   → 蓝色 #5050e0
通用         → 白色 #e0e0e0
```
