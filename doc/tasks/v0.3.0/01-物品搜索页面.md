### 2. 搜索交互

- [ ] 回车键触发搜索
- [ ] 输入防抖 300ms（输入停止 300ms 后自动搜索）
- [ ] 搜索中显示 loading 动画（ProgressIndicator）
- [ ] 空结果友好提示："未找到匹配的物品"
- [ ] 错误处理：网络/数据库异常提示

### 3. 结果列表

- [ ] 每行显示：物品名、中文名、类别、等级需求
- [ ] 按稀有度着色：
  - 普通 `#c8c8c8`、魔法 `#8888ff`、稀有 `#ffff77`、传奇 `#af6025`
- [ ] 点击列表项 → 右侧显示详情 + 异步加载完整数据

### 4. 详情面板

- [ ] 物品名称（带稀有度颜色）
- [ ] 物品类别 + 基底类型
- [ ] 需求属性（等级、力量、敏捷、智慧）
- [ ] 固定词缀列表
- [ ] 传奇专属词缀
- [ ] 背景描述文字（斜体）
