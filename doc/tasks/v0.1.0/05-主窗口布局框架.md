# T-005 主窗口布局框架

**版本**：v0.1.0  
**模块**：`app-ui`  
**预估**：0.5 天  
**前置**：T-003, T-004  
**状态**：开发中

---

## 任务描述

实现主窗口的 BorderPane 布局：左侧导航菜单 + 右侧多标签内容区 + 底部状态栏。

## 详细步骤

### 1. 整体布局结构

```
┌──────────────────────────────────────────────┐
│  Menu Bar (可选)                              │
├──────────┬───────────────────────────────────┤
│          │  TabPane (多标签内容区)            │
│  导航菜单  │  ┌─────────────────────────────┐ │
│          │  │                             │ │
│  物品搜索  │  │   当前页面内容               │ │
│  技能宝石  │  │                             │ │
│  天赋树   │  │                             │ │
│  装备模拟  │  │                             │ │
│  设置     │  │                             │ │
│          │  └─────────────────────────────┘ │
├──────────┴───────────────────────────────────┤
│  状态栏: 数据版本 | 同步时间 | 状态信息       │
└──────────────────────────────────────────────┘
```

### 2. 导航菜单 (Sidebar)

```java
public class Sidebar extends VBox {
    public Sidebar() {
        // 宽度 200px，可折叠（ToggleButton 控制）
        setPrefWidth(200);
        setMinWidth(48);  // 折叠后宽度
        
        // 菜单项列表
        getChildren().addAll(
            new NavButton("物品搜索", "item-icon"),
            new NavButton("技能宝石", "gem-icon"),
            new NavButton("天赋树", "tree-icon"),
            new NavButton("装备模拟", "craft-icon", true),  // 灰度显示
            new NavButton("设置", "settings-icon")
        );
    }
}
```

### 3. 导航按钮 (NavButton)

- [ ] 默认状态：图标 + 文字，左侧显示
- [ ] 选中状态：左侧强调色边框 + 背景高亮
- [ ] 禁用状态：灰度显示，显示 Tooltip "开发中"
- [ ] 点击事件：触发 `NavigationEvent`，右侧切换对应 Tab

### 4. 内容区 (TabPane)

- [ ] 每个功能页面对应一个 Tab
- [ ] Tab 支持关闭（设置页除外）
- [ ] 同一功能不可重复打开（点击导航切换已有 Tab）
- [ ] 每个 Tab 内容为对应功能的占位页面

### 5. 状态栏 (StatusBar)

```java
public class StatusBar extends HBox {
    private Label dataVersion;   // "数据版本: 3.24"
    private Label syncTime;      // "上次同步: 2024-01-01 12:00"
    private Label status;        // "就绪" / "同步中..."
    private ProgressBar syncProgress; // 同步进度
}
```

## 验收标准

- [ ] 点击导航菜单，右侧打开对应页面
- [ ] 已打开的功能页不会重复打开
- [ ] "装备模拟"显示为灰度禁用状态
- [ ] 状态栏显示默认信息
- [ ] 窗口缩放时布局自适应
