## 任务描述

## 详细步骤

### 1. 创建 `app-core/build.gradle.kts`

```kotlin
plugins {
    java
}

dependencies {
    implementation(project(":common"))
    
    // Guava EventBus
    implementation("com.google.guava:guava:33.0.0-jre")
}
```

### 2. 配置目录结构

```
{user.home}/.poe-tool/
├── config.json          # 应用配置
├── data/                # 数据缓存目录
│   └── poe.db           # SQLite 数据库
└── logs/                # 日志文件
```
