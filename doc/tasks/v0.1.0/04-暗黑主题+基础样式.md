# T-004 暗黑主题 + 基础样式

**版本**：v0.1.0  
**模块**：`app-ui`  
**预估**：0.5 天  
**前置**：T-003  
**状态**：待开始

---

## 任务描述

集成 AtlantaFX 暗黑主题，编写自定义 CSS 样式，使 UI 风格与流放之路游戏色调一致。

## 详细步骤

### 1. 集成 AtlantaFX 主题

在 `PoeApplication.start()` 中加载主题：

```java
Application.setUserAgentStylesheet(new PrimerDark().getUserAgentStylesheet());
```

### 2. 创建自定义 CSS

文件：`src/main/resources/theme/dark-theme.css`

```css
.root {
    /* 主色调 */
    -fx-base-background: #1a1a2e;
    -fx-panel-background: #16213e;
    -fx-accent-color: #d4a853;
    -fx-text-color: #c8c8c8;
    -fx-text-muted: #888888;
    -fx-selection-color: #3a3a5c;
    -fx-border-color: #2a2a4a;
    
    /* 稀有度颜色 */
    -fx-rarity-normal: #c8c8c8;
    -fx-rarity-magic: #8888ff;
    -fx-rarity-rare: #ffff77;
    -fx-rarity-unique: #af6025;
    -fx-rarity-currency: #aa9e82;
    -fx-rarity-gem: #1aa29b;
    
    -fx-background-color: -fx-base-background;
    -fx-text-fill: -fx-text-color;
}
```

### 3. 自定义组件样式

- [ ] **ScrollBar** — 暗色滚动条，悬停高亮
- [ ] **TabPane** — 暗色标签页，选中标签强调色
- [ ] **TableView** — 暗色表格，交替行色
- [ ] **TextField** — 暗色输入框，聚焦边框强调色
- [ ] **Button** — 默认暗色 + 强调色悬停效果
- [ ] **Tooltip** — 暗色背景，金色边框

### 4. 加载自定义 CSS

```java
scene.getStylesheets().add(
    getClass().getResource("/theme/dark-theme.css").toExternalForm()
);
```

## 验收标准

- [ ] 窗口整体为暗色风格
- [ ] 主色调为深蓝黑 + 暗金强调色
- [ ] 文本在暗色背景下可读
- [ ] 所有基础组件样式统一
