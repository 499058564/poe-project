## 任务描述

基于 Guava EventBus 封装应用级事件总线，定义核心事件类型，实现模块间解耦通信。

## 详细步骤

### 1. 封装 EventBus

```java
package com.poe.core.event;

public final class AppEventBus {
    private static final EventBus SYNC_BUS = new EventBus("poe-sync");
    private static final AsyncEventBus ASYNC_BUS = 
        new AsyncEventBus(Executors.newFixedThreadPool(4));

    public static void register(Object subscriber) {
        SYNC_BUS.register(subscriber);
        ASYNC_BUS.register(subscriber);
    }

    public static void unregister(Object subscriber) { ... }

    /** 同步发布（当前线程执行） */
    public static void postSync(Object event) {
        SYNC_BUS.post(event);
    }

    /** 异步发布（后台线程执行） */
    public static void postAsync(Object event) {
        ASYNC_BUS.post(event);
    }
}
```

### 2. 定义核心事件

```java
// 导航事件
public class NavigationEvent {
    private final String source;   // 来源页面
    private final String target;   // 目标页面
}

// 数据同步事件
public class DataSyncStartEvent {
    private final String tableName;
    private final int totalRecords;
}
public class DataSyncProgressEvent {
    private final String tableName;
    private final int current;
    private final int total;
}
public class DataSyncCompleteEvent {
    private final String tableName;
    private final int syncedRecords;
    private final long durationMs;
}

// 配置变更事件
public class ConfigChangedEvent {
    private final String key;
    private final String oldValue;
    private final String newValue;
}
```

### 3. 典型使用示例

```java
// UI 层触发搜索
AppEventBus.postAsync(new SearchEvent("Mageblood"));

// core 层订阅处理
@Subscribe
public void onSearch(SearchEvent event) {
    List<Item> results = itemService.search(event.getKeyword());
    AppEventBus.postSync(new SearchResultEvent(results));
}
```

## 验收标准

- [ ] 同步事件在当前线程执行
- [ ] 异步事件在后台线程执行
- [ ] 订阅者注册后能接收事件
- [ ] 取消注册后不再接收事件
- [ ] 单元测试覆盖核心事件流
