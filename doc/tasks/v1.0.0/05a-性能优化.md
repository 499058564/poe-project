# T-036a 性能优化

**版本**：v1.0.0  
**模块**：所有模块  
**预估**：0.5 天  
**前置**：所有功能完成  
**状态**：待开始

---

## 任务描述

全面性能优化：启动速度、内存占用、UI 渲染帧率。

## 详细步骤

### 1. 启动优化（目标 < 3s）

- [ ] 延迟加载非核心模块（Lazy Initialization）
  - 首屏只加载导航框架 + 物品搜索
  - 其他 Tab 内容首次点击时才初始化
- [ ] 数据库连接池预热
  - `DatabaseManager.init()` 提前到应用启动时
  - 避免首次查询时的冷启动延迟
- [ ] JavaFX Preloader 显示启动画面
  - 显示加载进度

### 2. 内存优化（目标 < 512MB 空闲）

- [ ] 图片资源 LRU 缓存
  - 最多缓存 200 张图片，超限淘汰最久未用
- [ ] 天赋树节点对象池
  - 复用 Node 渲染对象，避免 GC 抖动
- [ ] 大查询结果流式处理
  - `ResultSet` 逐行读取而非全量加载到内存

### 3. UI 渲染优化

- [ ] 天赋树 30+ FPS
  - 增量渲染（只重绘变化区域）
  - requestAnimationFrame 节流
- [ ] 搜索结果虚拟化列表
  - 只渲染可见行 + 上下各 5 行缓冲
- [ ] 大量数据表格延迟渲染
  - 超过 1000 行时分批渲染

## 验收标准

- [ ] 冷启动 < 3s
- [ ] 内存占用 < 512MB
- [ ] 天赋树 30+ FPS
- [ ] 搜索 5000 条结果不卡顿
