## 任务描述

增强应用稳定性：全局异常处理、数据备份、网络容错。

## 详细步骤

### 1. 全局异常处理

```java
// JavaFX 主线程
Thread.setDefaultUncaughtExceptionHandler((thread, ex) -> {
    log.error("未捕获异常", ex);
    Platform.runLater(() -> showErrorDialog(ex));
});

// 后台线程池
ExecutorService executor = Executors.newFixedThreadPool(4, r -> {
    Thread t = new Thread(r);
    t.setUncaughtExceptionHandler((thread, ex) -> log.error("线程异常", ex));
    return t;
});
```

### 2. 数据备份

- [ ] 每次启动时自动备份数据库
  - 备份到 `~/.poe-tool/data/backup/poe_{date}.db`
  - 保留最近 5 个备份
- [ ] 配置文件备份
  - 保存前先写临时文件，成功后再替换（防写坏）

### 3. 网络容错

- [ ] 所有网络请求统一超时（30s）
- [ ] 失败重试（3 次，指数退避）
- [ ] 网络断开 → 自动切换离线模式
  - 使用缓存数据
  - 状态栏显示"离线模式"
- [ ] 网络恢复 → 自动重新同步

### 4. 数据完整性

- [ ] 配置文件格式校验
- [ ] 数据库启动时检查完整性（`PRAGMA integrity_check`）
- [ ] 数据损坏 → 提示用户重建数据库
