## 任务描述

实现自动化做装推荐引擎：根据目标词缀组合，生成多个制作方案并按成本排序。

## 详细步骤

### 1. CraftingAdvisor

```java
public class CraftingAdvisor {
    private final CraftingSimulator simulator;
    private final AiProvider aiProvider;

    /**
     * @param targetItem 目标物品基底 + 目标词缀
     * @param budget 预算上限（混沌石）
     * @param maxPlans 最多返回几个方案
     * @return 制作方案列表（按总成本升序）
     */
    public List<CraftingPlan> recommend(
            ItemBase targetItem, double budget, int maxPlans) { ... }
}
```

### 2. CraftingPlan

```java
public class CraftingPlan {
    String name;                       // 方案名称："改造石洗前+锁前洗后"
    String strategy;                   // 策略描述（AI 生成）
    List<CraftingStep> steps;          // 制作步骤
    CostEstimate cost;                 // 成本估算
    double successRate;                // 成功率
    double riskLevel;                  // 风险等级 0~1（1=最危险）
    int estimatedAttempts;             // 预估尝试次数
}
```

### 3. 方案生成策略

```java
// 策略 1：暴力随机（改造石 + 增幅石）
// 策略 2：化石点（利用化石标签限制词缀池）
// 策略 3：精华点（固定一条词缀 + 随机其他）
// 策略 4：花园工艺（定向添加/移除词缀）
// 策略 5：锁前/锁后 + 庄园/化石
// 策略 6：觉醒石合成（双势力装备）
// 策略 7：AI 自由组合策略

// 每个策略生成方案 → 模拟计算成本 → 按成本排序 → 返回 top N
```

### 4. 成本计算

```java
// 每步成本 = 通货成本 × 期望次数
// 通货价格从 poe.ninja 缓存获取
// 累计成本 = Σ(步骤成本)
// 风险等级 = 1 - 成功率
```

- [ ] 风险等级标注正确
